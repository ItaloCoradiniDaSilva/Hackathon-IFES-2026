# Local Shop 🛍️
## Sobre o projeto

O **Local Shop** é um aplicativo desenvolvido durante o Hackathon IFES 2026, com a proposta de conectar pessoas interessadas em comprar e vender produtos.

A aplicação busca facilitar a negociação entre usuários, permitindo a publicação de produtos e a busca por ofertas em uma plataforma simples e acessível.

## Funcionalidades

- **Cadastro de usuários:** registro com nome, CPF, data de nascimento, e-mail e senha.
- **Publicação de produtos:** cadastro de produtos com fotos, descrição, preço e categoria.
- **Pesquisa de produtos:** busca por ofertas disponíveis na plataforma.
- **Negociação:** possibilidade de negociar produtos com outros usuários.

## Tecnologia utilizada

- **Flutter:** framework utilizado para o desenvolvimento da interface e da aplicação.

## Objetivos do projeto

- Desenvolver uma solução tecnológica para aproximar compradores e vendedores.
- Aplicar conhecimentos de desenvolvimento de aplicativos.
- Criar uma plataforma para publicação e pesquisa de produtos.
- Participar de uma atividade prática de desenvolvimento durante o Hackathon IFES 2026.
